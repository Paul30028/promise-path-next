# Bethel campaign（第一章《伯特利与艾城》四幕剧本、动态支线与 Crucible 策令）

**Status:** implemented · **Updated:** 2026-11-19 · [GDD](../../GDD.md) · [Implementation](implementation.md) · [Testing](testing.md)

服务于第四支柱 **「经文正典不可篡改，策略过程自由分支」**（决策 D-001, D-006）。将《创世记》13:1–18 亚伯兰重返伯特利筑坛、两家牧人因水草拥挤相争、以及亚伯兰礼让罗得先选约旦河平原的正典叙事，转化为四幕 RTS 战役，并融入游民星空双轨支线与 `r/aoe4` 最受好评的 *The Crucible* 三选一圣约策令。

## Rules
1. **四幕战役推进状态机（`act1_camp` → `act2_expand` → `act3_defense` → `act4_parting` → `resolved`）**：
   - **第一幕（立营寻水）**：亚伯兰与罗得返回伯特利与艾城之间；建立首座 `伐木货栈` 与 `副帐房舍`，使搬运工物流运转。
   - **第二幕（界石与时代演进）**：派工程先驱乌珥插界石扩地至北坡石矿或西侧古井，建造二选一时代Ⅱ地标（【橄榄梯田庄园】或【大马色备战营垒】）晋升「伯特利立约期」。
   - **第三幕（北岭群狼与护群会战）**：北岭狼王率狼群分两波冲击东南草场与北坡山口；玩家依托高地 `瞭望箭塔`、`家丁矛兵` 与 `家丁投石手` 肃清敌群。
   - **第四幕（你我不可相争 · 创 13:8–18）**：随两家羊群与采集活动增长，草场拥挤摩擦度达到临界；派亚伯兰前往东南草场与罗得对话，触发三分支礼让筹备抉择。
2. **三条可选动态支线（Side Objectives）**：
   - **支线 A【寻回迷途羔羊】**：派斥候以利以谢前往东北迷雾林地找回 2 只走散绵羊 → 奖励 `+60 粮草` 并触发 1 次圣约策令。
   - **支线 B【修复迦南古井】**：派工程先驱乌珥修复西侧荒废古井地标（耗 `25 木 + 15 石`）→ 永久每秒 `+1 饮水` 并触发 1 次圣约策令。
   - **支线 C【捣毁北岭狼穴】**：在狼王发动总攻前主动率队摧毁北坡狼穴前哨 → 获得 `+50 石料` 与 `+2 家丁和睦度`。
3. **Crucible 式「圣约策令」三选一（Mid-Match Perks）**：
   - 每当玩家完成时代晋升或任一支线，屏幕弹出三选一策令卡片（本局永久生效）：
     1. **【大马色青铜矛锋】**：所有家丁矛兵近战攻击 `+4`，架枪眩晕时间延长至 `1.2s`；
     2. **【山泉活水渠】**：所有蓄水站与水井交货效率 `+35%`，搬运工道路移速额外 `+15%`；
     3. **【守望双发烽火】**：石木瞭望箭塔每次攻击同时射出 `2 支火箭`，视野半径 `+3.0u`。
4. **第四幕正典分地三分支（Canon Anchor Guarantee）**：
   - 无论选择哪一分支，**均由亚伯兰主动提议和平分开、罗得举目先选约旦河全平原东迁、亚伯兰留在迦南得蒙土地与后裔应许（创 13:8–17）**：
     - **分支 1【共饮上泉，从容分群】**：消耗 `40 饮水`，和睦度 `+2`，羊群零损失；
     - **分支 2【赠材助迁，骨肉情深】**：消耗 `50 木料`，和睦度 `+3`，第二章《但地夜袭》开局获得罗得家仆报信的敌营视野；
     - **分支 3【急装分道，止息纷争】**：零物资消耗，匆忙分群损失 `30 粮草`，和睦度 `+1`。
   - **可选同行派遣**：勾选“派乌珥短途护送罗得至约旦渡口后归营”，将 `escortedByCompanion: true` 写入 `ChapterSummary`，在第二章解锁渡口捷径。

## Edge cases
- **玩家在未建时代Ⅱ地标前就清空了北岭狼群**：直接允许提前解锁第四幕与罗得议事，奖励速攻玩家，不卡死主线。
- **第四幕触发时饮水与木料均不足**：分支 3【急装分道】永远零资源门槛可用，确保 100% 不会在结局对话卡死。
