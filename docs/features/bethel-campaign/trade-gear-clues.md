# 伯特利旅途 · 商品、装备与线索设计 v0.1

设计供试玩审核。沿用 ch01_bethel.json 的驿道商队事件作为交易入口。以下地名细节、人物、价格、班次和任务均为原创试制参数。创 13:2、5–7 支持牲畜与牧地冲突的背景；创 23:16 提供称银交易的叙事例证。此处用银重作游戏计量，价格没有考古定价含义。

## 商品与报价

玩家有自有货、受托货和已装备物品三种持有状态，可在集市当面买卖或以物易物。下表为正常供应时商人收购／出售的银重。货格约束行装，牲畜另占畜群名额。

|商品 ID 与中英文名|收／售|占用与用途|
|---|---|---|
|grain 粮袋 / Grain sack|2／3|1 格，一袋供应一班远行|
|fodder 干草 / Fodder|1／2|1 格，补一小群牲畜一班饲料|
|wool 羊毛束 / Wool bundle|3／4|1 格，剪毛后取得，可换成行装|
|salt 盐袋 / Salt pouch|2／3|1 格，受托运输的报酬或易货筹码|
|ewe 母羊 / Ewe|8／10|1 畜位；出售前显示下一繁育期减少的合格母畜数|
|ox 驮牛 / Pack ox|18／22|1 畜位；健康时提供 4 货格，跛行降至 2 格|

驿道商人有工具和银重，偏收羊毛；路过牧团可能缺草、有羊而少银，愿意易货。每个商队到站时固定库存、银重及一种公开行情，例如缺草时干草收／售改为 2／3。交易前并排显示交付、所得、补付银重及剩余容量；卖方收购价合计抵扣商人售价。例：一束羊毛抵 3 银重，再补 2 可换售价 5 的牧绳。所有报价在离站前稳定。商人余额不足可改易货或减少数量。容量按换完后的状态核算，出售驮牛会超载时可先卸货。受托母羊显示委托人，可归还、寻回或按约赔付，交易列表锁定。

跨季结算时，每只健康且满足饲养条件的自有繁育母羊在样章中最多新增一只幼羊；这是压缩的繁育模型。两次停站之间不重复繁育。总畜位不足先提示扩充牧养能力、出售或交托，保留待安置幼畜。银重与生畜没有跨时代继承。

## 装备与人员安排

每名队员一个主手位（工具或武器择一）和一个防护位，队伍一个共用运输装具位。营地或路口出发前可调换；遇险中换装消耗该队员一次行动。购买后先进货格，装备时移入对应槽位。卸装时先检查剩余货格。以下均为候选售价。

|装备|售价|携带者与局内效果|
|---|---:|---|
|牧绳 Herd rope|5|牧人装备后，一次“分群”可额外接回一组走散的羊；若交给搬运者，可在候选事件中固定滑落的货包，两种用途占同一件|
|双罐肩带 Jar sling|4|取水者每趟运两份水；走窄径时占用双手，无法同时照看幼羊|
|驮架 Pack frame|8|共用槽，须有健康驮牛，容量加 2；牛受伤时行装保留，超额货须重新分配才能继续走|
|修补包 Repair kit|3|消耗品，整修一次损坏的运输装具；不能消除牲畜疲劳|

每件装备详情说明“谁能用／新增行动／会放弃什么”。首轮用角色、装备和地点三个条件组合，例如牧人＋牧绳＋散群，避免纯数值升级成为唯一解。

## 武力装备与护卫遭遇

每名可出勤的队员每回合有一次行动。选中武器可预览消耗、作用对象、敌方压力或具体资产的状态变化。护卫完成一次有风险的护送后可获得该类委托的资历记录，用于解锁更重的委托；下列属性均为玩法试值，装备外形与章节可得性需历史美术审核。

|ID 与双语名称|槽位、收／售银重|使用者与游戏动作|
|---|---|---|
|herd_staff 牧杖 / Herding staff|主手，2／4|牧人起始装备。“护群”使一组受惊牲畜本回合保持集结；牧绳则用于接回已经走散的羊。|
|sling 投石索 / Sling|主手，3／6|牧人或护卫。“驱离”消耗一次行动，使一次兽害遭遇的压力减 1。|
|guard_spear 护卫矛 / Guard spear|主手，5／9|护卫。“交锋”消耗一次行动，使一次劫掠遭遇的压力减 2。行动期间该护卫不能同时护送驮畜。|
|small_shield 小盾 / Small shield|防护，4／7|护卫。“掩护”消耗一次行动，给一个掉队队员或一头驮畜一次保护，抵消本回合首次损失。|
|guard_vest 护身衣 / Guard vest|防护，3／6|出勤队员。每场首次受伤降为疲劳；疲劳会影响下一站劳动。与小盾争用防护位。|

普通牧团可交换牧杖与投石索，护卫矛与小盾由有护卫的商队限量出售。报价沿用商品估价与差额支付。能力按角色与物件绑定，同行者受伤离队后允许回营重新分配装备。敌方身份取决于当次事件，来往牧团也可以是交易伙伴或托运人。

试局“渡口失散”：开场显示兽群逼近和自家驮畜落后。若由牧人护群、持盾护卫掩护驮畜，本回合羊货可保，危险仍在；改让牧人驱离，压力会降，但可能留下走散的羊供后续寻回。商旅报告出现劫掠者时，可花 9 买矛取得交锋选项，也可保留银重带货绕路。首次试制每场最多三回合，每回合公开一个将受影响的目标；压力清零即脱险。最后一回合仍有压力时仅结算已预告且未保护的目标，写入丢失货批或寻回节点；一次损失只记一次。过场后记录保住了谁、遗失何物及疲劳状态。检查换装扣行动、同一护卫不能同时交锋和掩护、读档后盾的保护次数不会重置。

## NPC、线索和交叉验证

点有交谈标记的人物，第一句显示他的处境。对话主题由已见物件、同行角色与已知线索开放。听取一般消息免费；绕路查看证据或请向导带路消耗一班时间。重复问同一问题可重读，不重复扣费。每条地图情报记下来源、所指路段、有效班次、获知状态（听说／核实／已过时）。过时情报保留在日志，地图恢复未知。跳过交谈仍可按初始公开路线继续。

|人物|玩家怎样问|能得到什么，怎样改变玩法|
|---|---|---|
|守泉牧人|问“今天谁走过浅滩？”；带牧人可追问“羊是自己走过的吗？”|听说清晨羊群通行；追问得知幼羊其实由人抱过。地图分别显示成人通行与携幼畜的额外人手需求。|
|驮队商人|查看其货单后问“为什么驮架都卸了？”|他称重载车宜走山脊，并愿出售驮架。记录他是亲历者还是转述者，保留其交易利益作为玩家判断依据。|
|返程搬运者|出示浅滩消息或询问他的湿衣；可选择到岸边检查水位标记|核实本班浅滩只适合轻载，标在河谷节点。若商人说所有人都得绕行，日志并列两条说法，显示载重为何造成差异。|
|委托牧人|接托付前问白耳母羊的记号；归来时按实际交付再谈|解锁散群事件中的辨认选项。若少一只，自选赔付或承诺下一站寻回；寻回后对白与账目同时结清。|

示例对白：“我看见羊上了对岸。”“幼羊呢？”“在我肩上。你要带两只，就留一个人空着手。”英文：“I saw the flock reach the far bank.” / “And the lambs?” / “On my shoulders. If you take two, keep a pair of hands free.” 两种语言共用线索 ID 与费用，切换语言后保留已问主题。

## 一段可玩的取舍

开局自有 2 银重、一束羊毛、一头健康驮牛，以及受托羊群。先问牧人，再决定是否花一班核实水位。可交羊毛加 2 银重换牧绳，分配牧人经河谷照应散群；或保留羊毛，花 2 买干草走山脊，多出的饲料抵消绕路消耗。两路在交付点会合。若迟一班，早市收摊，少一个出售机会，但仍可找到委托人。玩家能从行装、人物对白和路线标签看到同一决定的三种结果。

## 内容字段与验收

商品定义记录稳定 ID、类型、容量、基础收售价及译名键；具体货批记录物主、数量与委托 ID。装备实例记录所在槽、持有人、行动标签及使用次数。对话主题记录角色 ID、出现条件、文本键、所授线索和效果 ID。线索记录来源、适用路段、载重条件和过期班次。保存商人库存、行情、队员装备、畜群及对话进度；交易确认、交付和赔付各自一次结算，重读对白不重发奖励。

首轮验收覆盖银重购买、混合易货、余额不足、超载、误售受托羊、两人争用同一牧绳、略过消息仍可通关，以及读档后用另一语言核实同一消息。方舟建造章节可复用物资、工具位与知情工人对话，交易节点按章节处境设置。
