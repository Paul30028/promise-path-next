# Territory and building（工程先驱扩地、自由建造与地标演进）

**Status:** implemented · **Updated:** 2026-11-19 · [GDD](../../GDD.md) · [Implementation](implementation.md) · [Testing](testing.md)

服务于第一与第二支柱（决策 D-004）。玩家通过**工程先驱（乌珥）**向外敲击界石扩张领土、勘探野外矿脉与古井地标，并在已控制领土内的任意合法空地通过**绿/红建筑虚影**自由规划伐木货栈、副帐房舍、石木瞭望箭塔与家丁哨营，最后通过二选一地标实现时代晋升。

## Rules
1. **领土圈与工程先驱扩地（Settlers Territory）**：
   - 开局 `主营大帐` 拥有半径 `10.0u` 的初始领土圈（地面显示柔和的古金/青铜色领土边界线）；
   - 玩家仅可在**本方领土圈内**放置新建筑；
   - 派工程先驱（乌珥）前往领土边缘的**界石桩点（Boundary Post）**或野外矿点读条 `3.0s`，即可将该区域（半径 `7.5u`）并入本方领土并揭示周边石矿。
2. **自由选址与绿/红虚影校验（AoE Placement Ghost）**：
   - 在左下 `3×4` 建造面板点选建筑图标后，进入选址模式，地面跟随鼠标/触控点显示该建筑的半透虚影与占地圆环；
   - **绿色虚影（可建）**：处于本方领土内、距其他建筑中心 `>= 2.4u`、不处于水域或陡峭崖壁，且未完全封死主帐出入口；
   - **红色虚影（禁建）**：越出领土、与现有建筑/树木重叠或资源不足；
   - 点击确认落址后，立即扣除对应资源并生成**石木地基（`progress = 0`）**，自动指派当前选中的工程先驱或搬运工前往敲锤施工；支持多人协同建造（每增加 1 名工人，施工速度 `+65%`）。
3. **野外中立地标争夺（Settlers Landmarks）**：
   - 地图散布 2 处中立遗址地标：**「迦南古旧水井」**（西侧绿洲北缘）与**「上古立石望台」**（北坡中段）；
   - 派工程先驱靠近并交付指定物资（如古井需 `25 木料 + 15 石料`），读条修复后立即提供永久全局增益（古井：每秒自动产出 `+1 饮水`；立石望台：永久点亮北坡狼群走廊视野）。
4. **地标二选一时代晋升（AoE4 Landmark Age-Up）**：
   - 当营地处于时代Ⅰ「南地游牧期」且集齐 `150 粮草 + 80 木料 + 40 石料` 时，可从建造栏选择建造以下两座时代Ⅱ地标之一以晋升至**「伯特利立约期」**：
     - **经济地标【橄榄梯田庄园】**：建成后每 `5s` 自动产出 `+8 粮草` 与 `+5 饮水`，并使周围牧场羊群产量提升 `30%`；
     - **军事地标【大马色备战营垒】**：建成后本身即具备双倍产能的兵营功能，立即免费赠送 `2 名家丁矛兵`，并解锁铁匠摊攻防科技。

## Edge cases
- **施工中途工人被狼群攻击或调走**：地基保留已完成的 `progress` 与生命值，后续任意工人右键点击该地基即可继续施工直至 `100%`。
- **取消未完工地基**：施工进度 `< 50%` 时取消返还 `75%` 资源；`>= 50%` 时返还 `50%` 资源。
