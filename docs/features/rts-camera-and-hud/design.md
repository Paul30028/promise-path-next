# RTS camera and HUD（框选操控、45° 实时光影与 AoE 三段式 HUD）

**Status:** implemented · **Updated:** 2026-11-19 · [GDD](../../GDD.md) · [Implementation](implementation.md) · [Testing](testing.md)

服务于第三支柱 **「轻写实微缩与纯正古希伯来考据」**（决策 D-002）。严格按照 [aoe-v5-scene-concept.png](../../../design/codex-v5-aoe/aoe-v5-scene-concept.png) 原稿示范的 **《帝国时代》经典三段式青铜羊皮卷 HUD** 与 **45° 等距实时软阴影战场** 实现跨端操控与视觉呈现。

## Rules
1. **桌面与移动端双模 RTS 操控**：
   - **左键点选 / 拖拽框选（Marquee Box Selection）**：在战场上按住左键拖拽超过 `10px` 拉出金青色半透选框，松开后选中框内所有本方可控单位；双击某单位自动全选当前屏幕内同兵种单位。
   - **右键万能上下文（Right-Click Context）**：
     - 右键点击空地 → 计算多单位方阵/散兵阵偏移点并行军（绝不重叠在同一点）；
     - 右键点击资源点 → 指派选中搬运工开启自动采集与就近交货循环；
     - 右键点击未完工建筑地基 → 指派工程先驱/工人协同建造；
     - 右键点击敌方狼群 → 指派选中战斗单位集火或包抄。
   - **移动端触控适配**：单指拖动平移相机，点击单位选中，顶栏/底栏提供「框选/多选开关」与直观的目标动作按钮，所有交互按钮尺寸 `>= 44×44 CSS px`。
2. **帧率无关阻尼相机（`camera-systems` 规范）**：
   - 相机平滑跟随与切屏统一采用指数衰减阻尼 `t = 1 - Math.exp(-8 * delta)`，禁止使用帧率相关的固定 `lerp(0.1)`；
   - 支持滚轮与 `+ / −` 按钮在 `0.55×`（近景观察搬运与敲锤）至 `1.65×`（全谷战略俯瞰）之间缩放，并按当前缩放比例动态裁剪相机边界，绝不露出地图黑边。
3. **45° 地中海实时光影与三层平滑迷雾（`threejs-materials-lighting` 规范）**：
   - 开启 WebGLRenderer `PCFShadowMap` 软阴影；配置 45° 斜射主太阳光（`DirectionalLight`，强度 `2.4`，阴影贴图 `2048×2048`）与天空/大地半球补光（`HemisphereLight`）；
   - 地表采用高分辨率程序化混合 Canvas 纹理（草地、运货沙土路、北坡石灰岩、西侧绿洲水岸）；
   - 战争迷雾采用 `64×48` 双线性平滑插值遮罩纹理（`0 = 未探索浓雾`，`1 = 已探索半透暗影`，`2 = 实时明亮视野`），彻底消除低模方格锯齿。
4. **经典 AoE 三段式 HUD 架构（`game-ui-ux` 规范）**：
   - **顶部资源与全局条**：左起章节名《伯特利与艾城 · 创 13》，中部为 `粮草`、`饮水`、`石料`、`木料`、`和睦度`、`人口 (当前/上限)` 与 **【空闲工人一键定位】** 按钮，右侧为时代徽章、十二圣约石、暂停/倍速与语言切换。
   - **左下 `3×4` 建造与指令网格**：12 格复古羊皮卷图标按钮（`主帐`、`副帐房舍`、`伐木货栈`、`采石场`、`石木瞭望塔`、`家丁哨营`、`十二石祭坛`、`牧场`、`水井蓄水站`、`时代地标`、`铺设道路`、`召集号角`）。
   - **中下选中编队与生产面板**：左侧显示当前领队大头像（如亚伯兰/撒莱/乌珥），右侧横向排列已选各兵种分组卡片（显示兵种立绘、数量角标与分组总血条）或当前选中建筑的训练/建造进度队列。
   - **右下 45° 菱形等距战术小地图**：旋转 45° 的菱形金属框小地图，实时绘制地形、平滑迷雾、蓝色我方单位/建筑、红色敌方狼群脉冲与白色相机视口框，支持点击/拖拽瞬间切屏，左侧附带一键回主帐、视野切换与集结旗按钮。

## Numbers
| Name | Value | Unit | What to watch in playtests |
|---|---|---|---|
| `CAMERA_DAMP_RATE` | 8.0 | 1/s | 切屏与跟随在不同刷新率显示器上是否同样顺滑 |
| `ZOOM_MIN` / `ZOOM_MAX` | 0.55 / 1.65 | × | 拉近看微缩人物细节与拉远看全图防线的平衡 |
| `MARQUEE_DRAG_THRESHOLD` | 10 | px | 区分“单击选人”与“拉框多选”的防误触阈值 |
| `FORMATION_SPACING` | 1.15 | world units | 多选行军时的方阵单位间距 |
| `MIN_TOUCH_TARGET` | 44 | CSS px | 移动端横竖屏所有按钮的最小触控宽高 |
| `FOG_TEXTURE_RES` | 64 × 48 | texels | 线性插值后迷雾边缘的柔和度与每帧更新开销 |

## Edge cases
- **拉框选区同时框住工人与军事单位**：优先选中军事单位（或全部选中并在中下面板按兵种分组卡片展示，点击某兵种卡片可快速筛出该兵种）。
- **在 HUD 按钮上拖拽或滚轮**：所有 HUD 容器阻止 `pointerdown` / `wheel` 事件冒泡至 3D Canvas，防止点按钮时误触发地面行军或框选。
