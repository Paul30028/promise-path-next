# A 版黏土微缩立体美术规范 v0.1

参考图：`assets/references/a-clay-cast.png`。这是一张气质参考，不能直接当 3D 游戏资产。场景里过多碎石、植物和高饱和装饰会削弱手机端的操作识别；生产版需减少噪声，增强可交互物轮廓。

## 角色规格

成人基准 2.7 头身，允许 2.5—3.0；老人 2.5—2.7，儿童 2.2—2.4。世界单位成人高约 1.3—1.5，肩宽 0.42—0.56。头部略方圆，眼睛为深色小椭圆，鼻和嘴采用浅浮雕，避免玩具式大眼造成过度幼态。四分之三俯视 35—45° 时，头巾、肩部、手持物仍须可辨。

## 材质、场景与镜头

黏土主体采用哑光微粗糙，边缘有轻微手工不规则；织物保留可见经纬但不使用高频噪声；皮革半哑光；木材有简化年轮/束结；陶器有烧制色差；石材边缘磨圆。禁止塑料高光、强金属反射和大面积细密纹理。基准色：岩沙 `#D7BC8D`、亚麻 `#E7D6B8`、河水 `#7EAAA3`、橄榄绿 `#758B5C`、深蓝灰 `#304D70`、陶赭 `#B76962`。

地图按 1 单位≈1 米制作，常驻可玩区域约 18×15 单位。默认正交或弱透视 35—45° 俯视，角色屏幕高至少 48 px；互动目标在 390 px 手机宽度上可点区域至少 44×44 CSS px。点击轮廓、地面投影和选中圆环各有不同反馈。主光为低角度暖日光，柔阴影，环境补光保持脸部可读。夜间用营火局部暖光，不牺牲交互识别。

移动端目标首场景同屏 10 名角色、30 个可交互物、100 个装饰实例，场景贴图预算初稿 32 MB GPU 常驻。最终数字须用目标设备实测调整。每资产需交三视图、俯视小图、配色、材质球、尺寸、骨骼/动作表、LOD 和版权/来源记录。美术验收先做灰模与角色剪影测试，再做高质量材质和动画。商业化标准需人工建模、动画、灯光、美术总监审核及商用权利核对。
