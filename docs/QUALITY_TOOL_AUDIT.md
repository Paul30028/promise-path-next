## 立即采用顺序

1. **真实设备质量门槛。** 模拟器已验证 APK 启动、WebGL、英文切换、点击选人、取水和资源从 4 到 7；截图在 `design/ui-v2/android-emulator-action.png`。下一步测一台中端 Android 的帧率、内存、触控命中与首屏时间。当前模拟器结果不能代表真机性能。
2. **角色资产生产。** 以 A 版为约束制作亚伯兰正/侧/背三视图、头部表情与材质表，再制可编辑模型和骨骼动作。验收需同屏手机截图，不能只看单张概念图。
3. **UI 资源替换。** 用统一角色肖像替换字母头像；补操作状态、目标标记和任务反馈。中英文都要检查文本溢出。
4. **场景与交互。** 完成地形、水缘、帐棚布料、可走路径和移动避障，再验证装饰实例与阴影预算。
5. **历史与叙事核查。** 制作每章来源索引，对虚构角色、战斗和资源后果逐项标记改编。

## 当前 Android 发现

模拟器为 1080×2400 竖屏。游戏画面和触控流程正常，英文行动日志显示 “Nura brought back 3 water.”；没有发现应用崩溃。原生状态栏与导航栏为白色，破坏沉浸感，应在下一次 Android 视觉修订中处理。角色、地表与帐棚细节仍显著低于 A 版目标，不能判定达到商业发行质量。
