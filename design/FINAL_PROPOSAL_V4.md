## 一、 商业模式选型：为什么采用「三合一流行混合策略模式」？

基于全球畅销榜与 Steam 高口碑数据，纯传统 RTS（操作累、手机难玩）和纯文字 AVG（没商业深度、被当说教软件）均难以破圈。最适合《旧约》题材且经过市场验证的流行模式是以下**三大爆款基因的黄金组合**：

| 借鉴的流行爆款 | 抽取的核心流行机制 | 在《应许之路》中的本土化落地 | 商业与体验价值 |
| :--- | :--- | :--- | :--- |
| ***Whiteout Survival***<br>（无尽冬日 · 手游畅销 Top 1–2） | **中心圣火营地 + 一键委派气泡 + 英雄养成** | 中央为**本章祭坛/营火**，四周槽位一键升级帐棚、水井与练兵架；角色干完活头顶冒资源气泡一键收取；英雄分 **SSR/SR** 随旧约章节陆续入队 | **保次日留存（D1）**：30 秒看懂怎么玩，手机单手点击零挫败感 |
| ***Thronefall***<br>（王权陨落 · Steam 96% 好评） | **白昼极简建营 ↔ 夜晚爽快防卫（6–10 分钟单局）** | **白昼阶段**（省去繁琐排队，一键分派采集/建造/练兵）；**入夜/危机阶段**敌情来袭，守望台自动反击 + 玩家拖动英雄与家丁小队打一场 **60 秒快节奏防卫/突袭战** | **保核心爽感与心流**：把四维玩法（经营/建营/军事/战争）压缩进紧凑的昼夜节奏，不拖沓、不枯燥 |
| ***The Banner Saga* / *Pentiment***<br>（宿命叙事策略神作） | **收束式钻石分支 + 跨章同伴/物资继承** | **经文大结局固定，过程分支可变**：你决定先保民生还是先练兵、危机时硬刚还是火把威慑、离别前送多少补给与虚构同伴护送；抉择写入**跨章摘要**影响下一关 | **保重玩性与长线共鸣**：把“圣经剧透”转化为宿命感与照顾人的道德重量 |

## 二、 整部旧约脉络与「十二圣约纪念石」元界面（采纳 Codex 纠偏）

为了既实现你想要的**“完成一个环节就点亮祭坛一部分”**的强烈仪式感，又避免 Codex 指出的神学与历史混用问题（创 13 章是单座土石坛，出 24 章才立十二石柱），方案做如下优雅分层：

1. **外层选关大地图（Meta-Map）——「十二圣约纪念石」**：
   - 主界面是一座宏伟的**十二块未凿原石纪念环**（明确标注为*串联旧约各时代故事的艺术象征*）。全游戏共 12 个时代战役章，每通关一章，永久点亮主界面对应的一块**历史纪念石**，解锁该时代的建筑风格、兵种与英雄。
2. **单关场景内部（In-Level）——「本章祭坛 / 营火 4 阶段亮火」**：
   - 场景中央是符合该章历史语境的建筑（第 1 关是创 13:4 的**伯特利未凿原石祭坛**，第 5 关是出埃及的**会幕铜祭坛**）。
   - 关卡推进到 `立营 → 备战 → 护卫/战役 → 离别与应许` 四个阶段时，中央石坛圣火逐级燃旺、HUD 进度亮起，直观给出反馈（**注意：回体来自帐棚歇息、战力来自练兵与守望台，不把“祭坛敬拜”做成数值换取土地应许的交易机制**）。

### 十二章宏观战役与四维系统演进总表（核心精华版）
- **第一卷 · 列祖纪（创 12–22）**：`石 01 伯特利分群（创 13）` ➔ `石 02 但地 318 人夜袭（创 14）` ➔ `石 03 别是巴水井盟约（创 21）`
- **第二卷 · 出埃及与旷野（创 47–出 17）**：`石 04 歌珊丰荒粮仓与逾越` ➔ `石 05 利非订磐石出水与亚玛力之战（出 17）`
- **第三卷 · 征服与士师（书 6–士 7）**：`石 06 耶利哥七日绕城破阵` ➔ `石 07 基甸三百人瓦瓶火把夜袭（士 7）`
- **第四卷 · 王国与先知（撒上 17–王下 19）**：`石 08 以拉谷对峙与机弦甩石` ➔ `石 09 亚杜兰勇士游击救城` ➔ `石 10 攻取锡安大卫城` ➔ `石 11 撒玛利亚/希西家水道守城`
- **第五卷 · 归回（尼 2–6）**：`石 12 尼希米五十二日边战边筑耶路撒冷城墙`

## 三、 四维策略玩法与「收束式分支」架构

### 1. 怎么让玩家“一关内轻松玩懂四大系统”，又不觉得杂乱？
遵照 Codex 的减负建议，**不在第一关同时塞满完整科技树和四套操作教程**，而是用**一条短因果链**串起经营、建营、军事与战争：
> **采集（水/木） ➔ 建造（扩建帐棚 / 修简易瞭望哨与家丁整备） ➔ 实战（定格排位 + 情境指令击退山脊威胁） ➔ 抉择（带代价的分离方案，摘要继承到第二关）**

### 2. 收束式分支情节设计（严格恪守经文边界）
每一关提供 **2–3 个真实分支节点**，绝不反转圣经正典事实，只改变**过程代价、虚构同伴去向与下关初始局势**：

| 分支节点（以第 1–2 关为例） | 选项 A（民生 / 温和线） | 选项 B（备战 / 果断线） | 经文底线锁定（Canon Anchor） |
| :--- | :--- | :--- | :--- |
| **分支 1：昼间优先项** | **先搭第二座游牧帐棚**：体力恢复大幅提升，和睦 `+1`，但山脊零防御 | **先筑山脊瞭望岗并整备家丁**：提前获家丁哨兵守卫，但消耗木料且牧场维护人手不足推高摩擦 | 均需完成营地基本安顿后推进至黄昏 |
| **分支 2：山脊夜战（野兽危机）** | **火把威慑 / 绕行转移**：耗 `1木` 或 `1水` 零伤亡驱离野兽，惊动少、损耗小 | **亚伯兰/以利率家丁硬刚驱离**：省下资源，但若无足够防护或非专长人员带队，可能损失羊群或同伴负伤 | 本关保持**野兽危机**（移除会破坏创14因果的四王斥候） |
| **分支 3：创 13 分离准备** | **共饮上泉 + 派虚构同伴护送一程**：耗 `2水`，和睦 `+2`；第二关开局**解锁 1 条快捷暗道情报**与补给点 | **匆忙整装立即分开**：零水耗，但摩擦未平导致**走失 1 只羊**；第二关开局携带更多剩余木材，但缺少道路情报 | **所有分支都必由亚伯兰主动提议和睦，并由罗得先选约旦河平原东迁；最后共同见证创 13:14–17 应许** |

> **跨章摘要严格限流（防止状态爆炸）**：第一关通关只向第二关传递 **3 个轻量字段**：`分离方式（枚举）`、`短途护送是否完成（布尔）`、`剩余后勤等级（低/中/高）`——保证哪怕第一关打到最差结局，第二关《但地夜袭》依然 100% 可玩可通关！

## 四、 第一关《伯特利高地（创 13）》实机数值与节奏蓝图（`src/config.ts`）

单关目标时长：**首通教学约 8–12 分钟，重玩 6–8 分钟**。采用「阶段状态机（不靠真实时间读秒惩罚慢阅读玩家）」：

| 阶段 | 玩法重点 | 关键数值与防死锁规则（写入 `src/config.ts`） |
| :--- | :--- | :--- |
| **1. 抵达与分工** | 认识 6–7 名角色与底图 6 个区域 | 初始：`饮水 4`、`木料 1`、`帐棚 0（待建 1 座）`、`羊群 6`、`和睦 2`、`牧场摩擦 20%` |
| **2. 白昼一：民生与筑营** | 派夏甲（努拉）取水`+3`、乌珥（亚撒）收木`+3`，建造东北角帐棚 | 建帐棚固定槽位上限 `1`（防止无限刷分），消耗 `2木 1水`；**任何角色体力归零时仍可执行“前往主帐歇息”或被动回体，彻底消除死锁** |
| **3. 白昼二：瞭望备战与摩擦** | 决定剩余木料建**简易山脊瞭望岗（`1木`）**还是留作防卫/分离；牧场摩擦随行动阶段升至 `70%` | 固定阶段步长推进（`tick` 与界面隐藏/暂停严格解耦），同帧资源扣减统一校验，杜绝“一水两用” |
| **4. 危机：山脊夜狼** | 北侧山脊双狼逼近羊群，自动定格；可选用**瞭望岗+家丁护卫**或打出 3 张带插画的情境战术卡 | 3 张卡全部绑定真实资源与角色专长，零血腥驱离反馈 |
| **5. 高潮：礼让分离与亮石** | 亚伯兰向罗得让出选择权，玩家选分离准备方案；罗得东迁，**点亮第一块圣约纪念石** | 自动生成**章节跨章摘要存档**（仅在阶段切换/暂停时防抖写入 `localStorage`） |

## 五、 手机端与桌面端屏幕 UX 落地标准

基于对 `844×390` 横屏与 `390×844` 竖屏的实机裁切校验，采用以下工程铁律：

1. **交互减负（单指友好）**：
   - 手机端默认**单选角色**（点击角色头像或人物选中，点击地面/目标点即下达指令），长按或点「全队」才多选；
   - **单指拖拽永远只平移镜头，不触发误点移动**；点选新角色时镜头平滑居中一次，若玩家手动拖过镜头，立即暂停自动跟随（不抢手）。
2. **双端布局与 `>= 44px` 触控底线**：
   - **桌面端（`>=1024px`）**：全屏沙盘 + 四角轻量深色陶土悬浮 HUD + 底部插画战术手牌；
   - **手机横屏（`844×390`）**：**左侧约 66% 沙盘视口 + 右侧 `286px` 紧凑指令坞**（绝不上下夹扁视野）；所有头像、行动卡、执行按钮均满足 **`>= 44×44 CSS px`**；
   - **手机竖屏（`390×844`）**：**上方 `52%` 安全区沙盘视口 + 下方 `48%` 固定拇指操作区**（不把主按钮挤进滚动列表），并在视口下缘附带**「💧泉眼 / 🔥祭坛 / 🐑草场」一键飞镜胶囊**，一键直达屏外目标。
3. **美术资产统一就绪**：
   - 直接使用 Codex 本轮已产出的合规去阿拉伯化/去罗马化资产：
     - 可玩无人物底图：[level1-bethel-ground.png](file:///c:/AI/gemini/promise-path-next/design/codex-level1/level1-bethel-ground.png)
     - 六名性格化 Q 版角色切片：[level1-characters-sheet.png](file:///c:/AI/gemini/promise-path-next/design/codex-level1/level1-characters-sheet.png)（亚伯兰、撒莱、罗得、以利以谢、夏甲、乌珥）
