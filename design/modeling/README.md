# 首批可运行建模交付

本批资源由 `tools/model-assets.mjs` 创建，导出在 `public/models/`，已由 `src/World.tsx` 在真实 Three.js 场景中加载。截图 `first-batch-mobile.png`（390×844 浏览器视口）和 `first-batch-desktop.png` 是**实际 3D 运行画面**，与 `design/runtime-target/mobile-landscape-v1.png` 美术目标图分开保存。

| 类别 | 文件数量 | 几何预算实测 | 当前可用内容 |
|---|---:|---:|---|
| 七名角色 | 7 | 每人 4,236—5,088 三角面 | 身份轮廓、配色、头巾、胡须、服饰、手持物；手脚独立节点可做摆臂/迈步 |
| 营地与物件 | 7 | 352—1,204 三角面 | 完成帐棚、施工框架、陶罐、木捆、树、羊、泉水 |
| 合计 | 14 | `.glb` 总大小约 0.99 MiB，主画面估算 149 次绘制提交 | Web 场景已接入；Android/iOS 可随 `cap sync` 打包 |

## 质量检查结论

人物在手机截图中能靠主色和附属物区分，场景资源加载无报错。390×844 浏览器中已实际执行“收集木料→搭建帐棚”，确认工人停在帐棚外侧、模型切换为完成态、水与木料按规则消耗。当前模型是**可玩的第一版造型样板**，尚未达到 A 版原稿的商业美术质量：面部表情、织物与皮革细节、帐棚缝制与绳结、地形层次、羊群动画均需继续制作。角色没有骨骼蒙皮，目前用独立手脚节点做基础动作。手机镜头已放大并跟随选中人物，但目标设备的帧率、内存与触控仍未验证。

149 次为模型网格与场景物件的静态估算，不包含阴影绘制、后处理和运行时动态变化；须以目标手机 WebGL 计数器实测为准。

## 后续建模顺序

1. 先做亚伯兰角色精修：头巾、脸型、胡须、披肩、手杖，四方向剪影审查。
2. 用同一比例与材质体系精修撒莱、罗得，再扩展四名职能角色。
3. 帐棚增加门帘、布边与施工阶段；陶罐、木料与羊保持共享材质规则。
4. 地表增加可走路径、坡面、水缘和稀疏植被，逐项测量手机性能。
5. 补骨骼与动作：待机、走路、取水、搬运、施工、交谈、疲劳、警戒；输出重新验收的 `.glb`。

商业版资源的精修将继续由本项目执行。程序建模脚本是当前可编辑源文件；若后续引入 Blender，需将精修源文件和导出脚本一并纳入仓库，不只保存成品模型。
