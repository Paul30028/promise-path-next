# 《应许之路》(Path of Promise) — 三层圣经脉络史诗地图系统设计规范

> **状态**：已通过 Codex 首席系统策划与世界观架构师复核定型  
> **核心原则**：按《圣经·旧约》真实地理与救赎历史脉络构建地图系统；严格区分「经文正典锚点（Canon Anchor）」与「策略玩法改编（Adaptation）」；所有关卡、区域、事件与存档均采用数据驱动（Zero Hardcoding）。

---

## 1. 三层地图系统架构总览

| 层级 | 名称 | 核心职责 | 表现形式与移动端性能策略 |
| :--- | :--- | :--- | :--- |
| **宏观层 (Macro)** | **圣经地理战役画卷 (Overworld)** | 承载救赎历史纵深、多代主角迁徙路线、年代演变与全 12 章入口 | **可缩放古代近东—迦南地形画卷 + 动态迁徙路线节点**。不追求全境可行走，以地中海、幼发拉底河、约旦河谷、死海、尼罗河三角洲、红海、西乃山脉与远景城邦剪影呈现史诗尺度；同一地点随年代（列祖→出埃及→士师→王国）动态切换视觉状态；非军事章节采用「未抵达 / 未听闻」遮罩，战争迷雾仅用于军事章节。 |
| **中观层 (Meso)** | **章节战区大地图 (Chapter Region)** | 承载单章地理探索、牧区/水源调度、补给线、高地防守与多幕剧情推进 | 以第一章为例采用 **`128×96` 逻辑网格**（仅作逻辑尺度，非全图同屏渲染承诺）。通过**分块加载（Chunk Streaming）、近区精细模拟、远区简算**控制手机端 Draw Calls 与帧时间；先灰盒验证步行节奏与手机发热，再按块铺装精模。 |
| **微观层 (Micro)** | **营地经营与事件演出 (Camp Micro)** | 承载近景建造、亚伯兰/撒莱骨骼动画交互、对话抉择与祭坛献祭演出 | 无缝复用已验收的 **Godot 4.7.2 `v25` 实机管线**（12 套 CC0/MIT 手工精雕 3D 资产 + 14 骨骼 `AnimationTree` 状态机）。 |

## 3. 第一章《伯特利与艾城之间》（创 13:1–18）地理纵深与五幕闭环

### 3.1 创 13:3 真实地理锚点（`128×96` 七大分区，由西向东纵深展开）
> **经文依据**：*“他在伯特利和艾的中间，支搭帐棚，伯特利在西，艾在东。”*（创 13:3）

1. **远西剪影 · 伯特利山城**（高地远景地标，确立“伯特利在西”地理坐标）
2. **西北峡谷 · 枯竭旧井与活水山泉**（`Adaptation`：工匠修缮引水渠，解决全营与羊群饮水）
3. **中央高脊 · 亚伯兰主营台地与北坡旧坛**（`Canon Anchor`：深褐竖纹山羊毛主帐、草药棚、干砌矮墙与低矮不规则未凿原石旧坛）
4. **中东隘口 · 艾城石灰岩崖岭与驿道**（确立“艾在东”；含 `Adaptation` 原创支线：高地石矿、迦南商队驿道）
5. **东北幽谷 · 野狼巢穴与走失羊群**（`Adaptation`：原创护群遭遇战支线，明确标注非经文因果）
6. **东南低谷 · 罗得营地与争水牧场**（`Canon Anchor`：两家牛羊日增、承载力见顶，牧人争水争草前线）
7. **极东高崖 · 东望约旦平原观景台**（艺术化取景点：俯瞰远方滋润如耶和华园子的约旦全平原，触发谦让分地与应许）

### 3.2 五幕剧情闭环与正典/原创边界
| 幕次 | 剧情核心 | `Canon Anchor`（不可篡改） | `Adaptation`（可抉择策略过程） |
| :--- | :--- | :--- | :--- |
| **Act 1 · 归回伯特利** | 从埃及北上返抵伯特利与艾之间，整备营地 | 创 13:1–3 带着撒莱、罗得与甚多牲畜归回旧地 | 修缮枯井、搭建储水窖与草药棚，与撒莱/老管家对话 |
| **Act 2 · 重修旧坛** | 登高脊重修起初所筑之坛，求告耶和华的名 | 创 13:4 在起初筑坛的地方求告耶和华的名 | 清理坛基、筹备原石与献祭，解锁营地和睦与高地视野 |
| **Act 3 · 富足成压与牧人相争** | 牛羊日增挤占草场水源，两家牧人爆发争执 | 创 13:5–7 财物甚多、那地容不下他们同居；两家牧人相争（**不将罗得写成反派**） | 调配轮牧、护送弱小畜群、赔偿水源损失（可缓和摩擦但无法永久消除承载极限）；穿插原创支线「夜狼袭群」 |
| **Act 4 · 邻邦考验（支线）** | 艾城驿道迦南商队以青铜器/香料换取淡水 | 创 13:7 提及迦南人与比利洗人当时住在那地 | 公平交易 / 赠水结好 / 婉拒留存，影响补给成本与声望 |
| **Act 5 · 谦让分地、领受应许与南迁幔利** | 亚伯兰谦让罗得先选约旦平原；分离后领受应许并迁往希伯仑幔利橡树筑坛 | 创 13:8–18 **先谦让分离，后领受举目四望之应许**（应许为恩典，非任务兑换奖励），**最终南迁幔利橡树筑坛** | 分地时的赠礼安排（赠水/赠木/派人护送）影响家族和睦度与第二章初始士气 |

## 5. 三阶段工程落地路线（不推倒现有 `godot-pilot`）

- **Phase 1（剧情与状态机闭环）**：保留现有 `v25` 营地场景与 12 套 CC0 资产、亚伯兰/撒莱骨骼动画，接入 `ch01_bethel.json` 数据驱动章节状态机、NPC 对话与抉择面板，在现有营地内完整跑通「修井安营 → 重修旧坛 → 牧人争水 → 谦让分地 → 领受应许 → 启程幔利」五幕闭环。
- **Phase 2（`128×96` 七区扩容与手机端实测）**：先搭建七区灰盒地形、共享道路折线与分块加载（Chunk Streaming），在 Android 真机 APK 上实测步行节奏、Draw Calls 与帧时间后再铺装精模。
- **Phase 3（宏观战役画卷与跨章系统）**：接入全 12 章《圣经应许之路》可缩放 Overworld 画卷、迁徙路线推进动画、年代/主角切换与版本化存档迁移。
