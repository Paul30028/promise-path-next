## 一、 核心叙事与进度锚点：「十二圣约祭坛（The 12-Stone Covenant Altar）」

以《出埃及记》24:4、28:21 与《约书亚记》4:1–9“十二块石头立约”为精神原型，**「十二圣约祭坛」**贯穿整部游戏的宏观战役与单关微观进程：
- **单关内部（微观亮灯）**：每一关由 4 个核心阶段组成（**立营 → 备战 → 护卫/交战 → 立约**），每完成一个关键环节，中央祭坛上的对应石块便会**被圣火逐一点亮**，提供永久营地光环增益（如恢复体力、提升士气、解锁新兵种）。
- **整部旧约战役（宏观十二圣约）**：全游戏共设 **12 大历史战役章节**，对应旧约从列祖到归回的完整历史脉络；每通关一章，永久点亮主祭坛上的一块「历史圣约石」，解锁对应时代的营地建筑、兵种编制与旧约英雄：

## 二、 四维核心玩法系统（Strategy, Camp, Military, Warfare）

为了避免“只有单调收菜”，游戏将**经济、建造、军事、战争**深度咬合在同一张微缩沙盘中：

1. **策略经营（Strategic Economy）**：
   - **四大基础物资**：`饮水（Water）`、`木料（Timber）`、`石料/青铜（Stone/Bronze）`、`军粮/羊群（Provisions/Flock）`，外加核心指标 `家族和睦/士气（Harmony）`。
   - **空间承载与日消耗**：人员与兵力越多，每日饮水/军粮消耗越大；放牧过度会推高草场摩擦值，逼迫玩家在“扩充军备/牧群”与“维持补给平衡”之间精算。
2. **建造营地（Camp Construction）**：
   - 围绕中心**十二圣约祭坛**，地图预设可交互建造槽位（Slot）：
     - **黑毛游牧帐棚**：增加人口上限，提供高效率体力恢复；
     - **山脊守望台 / 石垒**：提供视野预警，入夜后自动向逼近的敌对目标投石/放箭；
     - **练兵场 / 武器架**：将普通牧人或家丁训练为武装部队（消耗木料/青铜与军粮）。
3. **建立军事（Military Organization）**：
   - 忠实于旧约记载的**古希伯来四大兵种**：
     - **家丁矛兵（Retainer Spearman）**：亚伯拉罕 318 家丁原型，前排持矛与皮盾卡位护卫营地；
     - **机弦投手（Slinger）**：如大卫与便雅悯人，远程投石驱离野兽、打断敌方冲锋；
     - **火把斥候（Torch Scout）**：如以利以谢与基甸三百人，夜间照明破除迷雾、威慑兽群与制造敌营混乱；
     - **弓箭手（Composite Archer）**：远程火力支援，配合守望台构建防线。
4. **战争与交战（Tactical Warfare）**：
   - 采用**「定格规划 + 实时推进（Real-Time with Pause）」**：玩家随时可定格沙盘，为英雄、工匠与士兵画出包抄/守卫路线，配合**情境战术卡**（如火把威慑、机弦齐射、分队包抄、兄长礼让）打赢以少胜多的关键战役。

## 三、 第一关《伯特利与艾城之间（创 13）》如何落地这四大系统？

第一关作为整部游戏教学兼完整体验的起点，不能只有“采水搭棚”，必须让玩家**完整体验「经营 → 建营 → 练兵 → 实战 → 点亮祭坛」**，同时自然引出第二关《创 14 章：但地夜袭》：

- **十二石祭坛 4 阶段点亮机制（Level 1）**：
  1. **点亮第 1–3 石（营地初立）**：汲水（夏甲）+ 收木（乌珥）+ 建成东北角**第二座游牧帐棚**；
  2. **点亮第 4–6 石（建军备战）**：在营地空地建造**「家丁练兵架 / 山脊守望台」**，派以利以谢招募并训练出首批 **2 名武装家丁（1 矛兵 + 1 机弦手）**；
  3. **点亮第 7–9 石（山脊保卫战）**：入夜后北侧山脊出现**野兽群与流寇斥候**，玩家定格指挥亚伯拉罕、以利以谢、大卫/乌珥与训练出的家丁配合**火把阵/机弦齐射战术卡**击退敌群、零损失保卫羊群；
  4. **点亮第 10–12 石（骨肉礼让与立约）**：平息罗得牧人争执，完成《创 13:8–18》礼让分离抉择，罗得东迁约旦河平原，**十二石祭坛圣火全亮**，并正式解锁第二关**《创 14 章：但地三百一十八人夜袭》**！
