# 游戏界面第二版：营地指令台

这是当前游戏实际运行画面的审核记录。截图为浏览器渲染的实时 3D 场景与可点击界面，不是静态概念图。

- `chinese-landscape-runtime.png`：844×390，中文横屏，初始营地。
- `english-portrait-runtime.png`：390×844，英文竖屏，初始营地。
- `chinese-desktop-runtime.png`：1440×900，中文桌面，包含选中人物状态。

## 界面规则

主视觉是可操纵的营地，不使用网页式全宽页头与长页面板。横屏场景占主要宽度，右侧按“目标→资源→选人→指令→执行”的判断顺序排列；执行/暂停按钮保持在指令台底部。选中人物后显示体力与待执行指令。竖屏缩短场景高度，首屏容纳五个常用行动。资源与指令都使用真实游戏状态更新。

色彩来自黏土、帐棚布、橄榄木和旧铜：指令台布色 `#EEE5D3`、深橄榄 `#283F35`、目标标记 `#55785B`、执行金 `#E9CB83`。标题用 Noto Serif SC，信息和操作用 Noto Sans SC；字体不可用时回退到系统字体。焦点有清楚轮廓，低动态偏好会关闭多余动画。

语言按钮切换简体中文与英文，语言偏好独立保存。任务、资源、角色姓名和职能、行动、提示、剧情抉择及行动反馈均跟随语言切换。存档仍记录中性的游戏状态；旧版中文日志通过当前本地化适配器显示英文，未来章节应改为事件 ID 与参数，避免依赖日志文本匹配。

## 本轮实际验证

- 844×390 横屏：五个常用行动与执行按钮同屏可见。
- 390×844 竖屏：五个常用行动与执行按钮同屏可见，按钮可点击。
- 英文取水：努拉取水后水从 4 变为 7，记录显示英文；刷新后资源与语言保留。
- 新存档显示开场；已有存档刷新不重复显示开场。
- 浏览器控制台无运行错误。此前缺失的图标已改为工程内 SVG。

## 仍需达到的商业标准

这次完成了界面结构和交互视觉的第二版，不代表整张画面已经达到商业发行质量。当前角色表情、帐棚布料、地形、动作和特效仍是造型样板。下一次美术验收应在目标 Android 设备上测量帧率、触控命中和内存；需用高质量角色肖像替代字母头像，并进行中英文母语审校。横屏极短设备的指令台仍可能滚动，正式版本需对目标机型逐一验收。
