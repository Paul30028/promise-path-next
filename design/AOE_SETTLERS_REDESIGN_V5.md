# 《应许之路》（Path of Promise）v5.0 设计与剧本全案
**核心定位：轻写实微缩 RTS《帝国时代 IV × 工人物语：新兴同盟》混合架构**

## 一、 双标杆最新机制拆解（Age of Empires IV × The Settlers: New Allies）

### 1. 《帝国时代 IV》（2024–2025 最新演进）可复用骨架
- **变体与地标时代演进（Landmark Age-Up）**：不靠枯燥读条升时代，而是建造二选一的**地标建筑**推进阶段（如“游牧行营” → “伯特利立约营”），不同地标决定本局经济或军事侧重。
- **经典 4 资源 + 人口软锁**：`饮水（Water）`、`木料（Wood）`、`羊群粮草（Food）`、`石料/铜矿（Stone/Ore）` + 房舍扩充 `人口上限`。
- **自由选址建造 & 高地作战**：玩家可在领土内任意空地摆建筑（绿/红虚影校验），用房舍/石墙卡路口；高地打低地获得 **+25% 伤害加成**。
- **三角克制与射弹**：`家丁矛兵（近战反骑/兽）` ↔ `投石手/弓手（远程风筝）` ↔ `轻骑斥候（突进切后）`；真实箭矢弹道。
- **历史战役 + Crucible（熔炉波次模式）**：主线为正典历史战役，通关可解锁随机词条波次守城模式。

### 2. 《工人物语：新兴同盟》（The Settlers: New Allies）可复用灵魂
- **自动物流搬运工（Carriers）+ 道路网**：建筑产出货品后，**专职搬运工沿道路自动在工坊、仓库与工地间流转**；土路升级石路或配驴车可提速。
- **工兵与兵源矛盾（Workforce Dilemma）**：搬运工同时是征召士兵的预备池——**暴兵过多会导致营地物流瘫痪**，天然防止无脑爆兵。
- **可控工程先驱（Engineers）**：玩家直接操控少量工程师**推进领土边界（Territory Expansion）**、勘探隐藏矿脉、修建建筑，并抢占野外**中立遗址地标（Landmarks）**交付物资换取永久增益。
- **3.5–4.5 头身轻写实微缩模型美学**：告别 2.4 头身大头萌系公仔，采用紧凑扎实、带 45° 实时阳光投影、装备与服饰细节清晰的微缩写实比例。

## 二、 融合重构方案：《应许之路》RTS 架构设计

### 1. 美术与渲染规范（3.5–4.5 头身轻写实微缩）
- **去阿拉伯化古希伯来考据**：未漂白亚麻袍配琉璃蓝（Tekhelet）与石榴红织边、青铜矛盾、未凿原石十二石祭坛、黑山羊毛编织凉亭大帐、石砌望楼、梯田橄榄林。
- **3D 渲染管线**：45° 地中海斜阳 `DirectionalLight` + `HemisphereLight` + **`PCFShadowMap` 实时落地阴影**；程序化混合地表（草地/沙土路/石灰岩高地/水岸）；高分辨率平滑三层战争迷雾（未探索 / 已探索 / 实时视野）。

### 2. 操控与 HUD（纯正 RTS 三段式）
- **桌面端**：左键点击/拉框多选单位；右键智能上下文（行军散开阵型 / 采集 / 协同建造 / 集火攻击）；`H` 回主营、`.` 一键定位空闲工程师/工人。
- **移动端**：保留左侧单选/框选切换、底部大触控命令格（`>= 44px`）、单指拖屏、双指或按钮缩放。
- **三段式 HUD**：
  1. **顶部**：4 资源（水/木/粮/石）+ 人口 `6/10` + 空闲人数 + 时代地标进度。
  2. **左下**：3×4 动态命令格（选工程师出建筑虚影，选主帐/哨营出训练与科技升级）。
  3. **中下**：多选头像矩阵 / 单选攻防与搬运状态 / 生产队列进度条。
  4. **右下**：等距菱形战争迷雾小地图 + 警报闪烁。

### 3. 核心游戏系统闭环
1. **领土与道路物流**：主营大帐自带初始领土圈；派遣**工程先驱（乌珥/以利以谢）**插界石扩地至森林与矿脉；在资源旁自由修建**伐木营 / 采石营**，由营地**搬运工**沿土路自动接力运回货栈。
2. **经济与征兵平衡**：主帐可训练**搬运工**（扩物流）与**工程先驱**（扩地建楼）；**家丁哨营**可将搬运工转职训练为**家丁矛兵**或**投石手**（受人口上限与物流人手双重约束）。
3. **野外地标争夺（Settlers 机制）**：地图散布“古井遗址”“迦南商队营地”“高坡石堆”等中立地点，工程师勘探后交付少量水/木即可激活永久增益（如全队移速 +15%、免费获得 2 只绵羊或石料）。
4. **地标时代升级（AoE4 机制）**：集齐资源后可建造地标升级至**「立约定居期」**——二选一：**【橄榄梯田庄园】**（经济线：羊群与饮水持续自动产出）或**【家丁备战营垒】**（军事线：解锁石制箭塔与青铜矛锋科技）。

## 四、 第一章详细可玩剧本：《伯特利与艾城》（创世记 13:1–18）

### 角色设定（3.5–4.5 头身轻写实微缩）
- **亚伯兰（族长 / 核心英雄）**：长袍佩青铜短剑与牧杖，具备“全队光环”与前线指挥能力。
- **撒莱（主母 / 营地统筹）**：提升主帐与蓄水/羊群后勤恢复效率，主掌和睦调解。
- **以利以谢（大马色管家 / 侦察与剑盾）**：高视野开图斥候，擅长护卫与拦截突袭。
- **乌珥（巧匠 / 工程先驱，改编角色）**：负责向外插界石扩张领土、勘探石矿与快速建造。
- **夏甲（汲水女仆 / 后勤主管）**：专精水泉与营地物流调度。
- **罗得（亚伯兰之侄 / 东营牧长，前期可控友军/后续剧情分离）**：看管东南草场羊群，随羊群增多与草场拥挤度上升触发矛盾。

### 四幕推进剧本
1. **第一幕：重返筑坛之地（开局立营）**
   - 亚伯兰一行从南地回到伯特利与艾城之间起初筑坛的地方。
   - **玩法**：用工程先驱向西扩地至山泉、向南扩地至相思树林；修建**伐木营**与**水泉蓄水站**，搬运工自动往返入库，并建**房舍副帐**扩充人口至 10。
2. **第二幕：界线与地标（《工人物语》式扩张）**
   - 派工程先驱勘探北坡石矿与野外地标**「古旧水井遗址」**（交付 2 木修复后永久提升饮水上限）和**「迦南石堆」**（获得建造石料）。
   - 建造地标升级进入**「伯特利立约期」**，解锁**石木瞭望箭塔**与**家丁哨营**。
3. **第三幕：北岭群狼与偷袭（AoE 防守反击）**
   - 暮色降临，北岭饥饿狼群与山谷掠食兽顺着坡道扑向东南羊群。
   - **玩法**：利用箭塔高地射程与家丁矛兵/投石手三角配合击退狼群（如果提前在北坡修好箭塔并设防，可零损失全歼）。
4. **第四幕：不可相争（创 13:8–18 核心抉择）**
   - 危难过后，两家牧人因水草争执达到顶点。亚伯兰主动走向罗得：**「你我不可相争……你向左，我就向右；你向右，我就向左。」**
   - **玩家三分支筹备**（决定第二章继承物资与和睦度，**均保留罗得先选约旦河平原东迁之正典结局**）：
     1. **共饮上泉，从容分群**（耗 2 水，和睦 +2，羊群无损）
     2. **赠予备材，礼让先行**（耗 2 木，和睦 +3，第二章获得罗得回报的同盟情报）
     3. **急装分道，止息纷争**（无物资消耗，走失 1 羊，和睦 +1）
   - **可选支线**：是否派乌珥护送罗得一程至渡口后归营（解锁第二章《但地夜袭》先遣路线视野）。
   - **结局**：点亮 **圣约石 #02《伯特利与艾城》**，亚伯兰迁往希伯仑幔利橡树下筑坛，保存战役档案进入第二章。

## 五、 基于《肥猫的秘密基地 (seicing.com)》AoE4 底层数据与机制落地

通过研读 [seicing.com 帝国时代系列资料库](https://seicing.com/html/index-aoeseries.html) 中《帝国时代 IV》的伤害公式、兵种标签、地标时代与蒙古游牧机制，以下核心规则将直接写入本项目 `config.ts` 与 `game.ts`：

### 1. 伤害与双护甲公式
- **三类伤害**：`Melee（近战）`、`Ranged（远程）`、`Torch（火焰/拆建筑）`。
- **双护甲分离**：每个单位独立拥有 `meleeArmor（近战甲）` 与 `rangedArmor（远程甲）`；建筑拥有高额 `rangedArmor` 与 `torchArmor`（火把拆迁专属）。
- **结算公式**：
  $$\text{实际伤害} = \max\Big(1,\ \text{基础攻击} + \sum \text{对目标标签的额外克制伤害} - \text{对应护甲}\Big)$$

### 2. 基础兵种标签与三角克制表
| 兵种 | 定位与标签 | 成本 | 克制目标（额外伤害） | 弱点与机制 |
|---|---|---|---|---|
| **家丁矛兵** | 轻甲近战步兵（反骑/反兽） | 粮 + 木 | 对 `骑兵 / 野兽` +12 额外伤害 | **架枪反冲锋（Brace）**；0 远程护甲，怕投石手风筝 |
| **投石手 / 弓手** | 轻甲远程步兵 | 粮 + 木 | 对 `轻甲步兵` +4 额外伤害 | 真实弹道飞行 + 高地 +25% 伤害；怕斥候骑兵贴脸 |
| **轻骑斥候 / 驼骑** | 轻骑兵（高移速 + 远甲） | 粮 + 水 | 对 `远程单位` +8 额外伤害 | 拥有 2 点远程护甲可抗箭雨；极怕矛兵架枪 |

### 3. 古希伯来游牧文明的“AoE4 变体特色”（借鉴蒙古与地标系统）
亚伯兰族落天然属于**古近东半游牧文明**，直接借鉴 `seicing.com` 记录的 AoE4 游牧与地标机制：
1. **游牧打包迁营（Camp Relocation）**：主帐与副帐支持打包成驴车队迁移到新水草地（第二章《但地夜袭》前线扎营极佳）。
2. **十二石祭坛 / 石堆光环（Oovo-style Aura）**：紧贴祭坛或采石场修建的哨营，获得训练速度 +25% 或额外产能加成。
3. **族长指令号角（Khan-style Signal）**：亚伯兰作为英雄单位拥有移速/护盾/攻速三选一指令光环，冷却驱动而不抢占普通兵种微操。
4. **铁匠铺 4 线科技整合**：前期无需额外“大学”，直接在营地铁匠摊研发 `熟铜矛锋（近战+1）`、`石磨矢石（远程+1）`、`合身亚麻皮甲（近甲+1）`、`青铜圆盾（远甲+1）`。

## 六、 游民星空《帝国时代4》专区 & Reddit `r/aoe4` 社区经验融合

结合 [游民星空 AoE4 专区](https://www.gamersky.com/z/ageofempiresiv/) 的战役/系统设计经验与 [Reddit r/aoe4 社区](https://www.reddit.com/r/aoe4/) 玩家最高频的褒贬反馈，新增以下四项关键进化：

### 1. 撒莱「主母督工」机制（借鉴游民专区重点解析的“命官监督 Supervise”）
- 撒莱不再只是普通采集员，而是拥有专属指令 **【督工统筹】**：
  - 驻扎在 **伐木营 / 蓄水站** 旁：工人交货时额外获得 **+25% 资源入库加成**；
  - 驻扎在 **家丁哨营 / 主帐** 旁：兵种训练与科技研发速度 **提升 50%**。

### 2. 主线 + 动态支线 + 「Crucible 熔炉策令」三选一（借鉴 `r/aoe4` 最受好评模式）
- 吸取 `r/aoe4` 对“纯线性脚本战役枯燥”的批评，引入 AoE4 玩家最喜爱的 *The Crucible* 局内构筑爽感：
  - **可选支线任务**：① 寻回北坡走散的 2 只迷途羔羊；② 修复古迦南废井；③ 捣毁北岭狼穴前哨。
  - **圣约策令（Mid-Match Perks 三选一）**：每当升级时代或完成支线，立即弹出三选一局内强化（如：`【大马色青铜刃】矛兵对野兽/骑兵额外伤害+40%`、`【山泉活水渠】每秒自动补充饮水`、`【守望相助】箭塔射程+25%且发射双发火箭`）。

### 3. 根治 `r/aoe4` 两大微操痛点：防卡位包抄 & 远程智能分火
- **防堵车半圆包抄（Anti-Traffic-Jam Steering）**：近战单位接敌时采用柔和流体分离力（Boids Separation）与弧形包抄槽位计算，杜绝多个矛兵围攻同一目标时互相卡住转圈。
- **远程防过量集火（Anti-Overkill Targeting）**：箭塔与投石手发射前先扣除“空中飞行箭矢的预估伤害（Pending Damage）”，若目标即将致死则自动转火下一敌人，消除远程火力浪费。

### 4. 武器轮廓与色彩高辨识度（Silhouette Readability）
- 响应 `r/aoe4` 社区对混战可读性的核心诉求：在 3.5–4.5 头身轻写实微缩比例下，适度强化武器与职能特征（双手长矛、旋转投石索、青铜圆盾、工程界石锤、背负双耳陶罐），并统一阵营识别色（亚伯兰本部：**琉璃蓝 Tekhelet**；罗得友军：**琥珀赭黄**；敌对狼群/四王掠夺者：**暗红黑铁**）。
